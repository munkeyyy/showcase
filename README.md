# Rohit — tactile collage portfolio v2

This rebuild follows the supplied screen recording much more closely: fixed paper canvas, scanned/cut-out desk objects, small pill navigation, object-to-edge transitions, irregular work frames, process rows, and the damaged-phone contact composition.

## Important asset note
For this private reference build, some desk-object/phone textures are temporary crops derived from the screen recording supplied in the chat so the layout and material treatment can be matched accurately. Before publishing, replace those temporary reference textures with your own scans/photos (or licensed assets) while keeping the exact same CSS positions and animation system.

## Run
```bash
npm install
npm run dev
```

Open http://localhost:3000.

Replace `/public/assets/proj-*.png` with real project screenshots and update portfolio links/copy in `app/page.tsx`.
